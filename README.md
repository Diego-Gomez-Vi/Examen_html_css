# 🌱 EcoMarket

## 📖 Descripción del Proyecto

EcoMarket es una tienda virtual que esta enfocada en la promoción y comercialización de productos ecológicos, reutilizables y sostenibles.

El proyecto fue desarrollado utilizando únicamente HTML5 y CSS3, aplicando principios de diseño responsive, maquetación semántica, Flexbox, CSS Grid y buenas prácticas de control de versiones mediante GitFlow.

El objetivo principal es ofrecer una experiencia visual atractiva que incentive el consumo responsable y contribuya a la concienciación ambiental.

---

## 🎯 Objetivos del Proyecto

- Promover productos sostenibles y ecológicos.
- Aplicar buenas prácticas de diseño web responsive.
- Implementar interfaces modernas utilizando únicamente HTML y CSS.
- Dominar Flexbox y CSS Grid.
- Gestionar el desarrollo mediante Git y GitHub.
- Desplegar una aplicación web estática en un entorno real.

## 🚀 ¿Por qué se eligió Netlify?

Para la publicación del proyecto se seleccionó **Netlify** debido a las siguientes ventajas:

- Permite desplegar proyectos HTML y CSS de forma rápida.
- Integración nativa con GitHub.
- Generación automática de una URL pública.
- Despliegues automáticos cuando se actualiza la rama principal.
- Certificado HTTPS gratuito.
- Excelente rendimiento para sitios estáticos.
- Fácil mantenimiento y administración.

## ⚙️ Proceso de Despliegue

1. Se creó un repositorio público en GitHub:

```text
EcoMarket_DiegoGomez
```

2. El proyecto fue desarrollado mediante GitFlow utilizando ramas independientes para cada funcionalidad.

3. Todas las funcionalidades fueron integradas posteriormente en la rama principal (`main`).

4. Se creó una cuenta en Netlify utilizando autenticación mediante GitHub.

5. Se autorizó el acceso de Netlify al repositorio.

6. Se seleccionó la rama:

```text
main
```

7. Netlify realizó automáticamente el despliegue del proyecto.

8. Se verificó el correcto funcionamiento de todas las páginas:

- Inicio
- Productos
- Sobre Nosotros
- Contacto

9. Se comprobaron las versiones responsive para:

- Móvil
- Tablet
- Escritorio

# 📱 Diseño Responsive

El proyecto fue construido siguiendo una estrategia Mobile First.

### Móvil

- Navegación adaptada.
- Productos en una sola columna.
- Formularios optimizados.

### Tablet

- Distribución en dos columnas.
- Mejor aprovechamiento del espacio.

### Escritorio

- Home: Grid de 3 columnas.
- Catálogo: Grid de 4 columnas.
- Valores ecológicos: 4 columnas.
- Testimonios: 3 columnas.
